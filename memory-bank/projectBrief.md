## Project Summary

A comprehensive database system for managing human resources across multiple organizations. The system supports multi-tenancy where a superadmin can create and manage admins, who in turn manage their organization's employee data, leave management, time tracking, and payroll operations.



## Goals

- Implement a multi-tenant HRMS database with at least 8 interconnected tables
- Support employee management with onboarding and actions tracking
- Implement comprehensive leave management system with policies, types, balances, and requests
- Create time and attendance management module
- Build payroll management with components, templates, and bonus management
- Enable admins to manage company profiles, departments, and settings
- Provide superadmin with full system access and admin management capabilities
- Create a dashboard visualization of key HR metrics



## Constraints

- No backend required - database-only implementation
- Must use MySQL and MySQL Workbench
- Minimum 8 interconnected tables required
- At least 10 sample records per table
- Must include full CRUD operations
- Minimum 10 SQL queries (3 JOINs, 2 aggregates, 1 ORDER BY/LIMIT, 1 subquery)
- Must implement indexing on at least one table
- Must demonstrate one transaction with COMMIT and ROLLBACK
- Dashboard must visualize database content (no backend)
- Project deadline: January 11, 2026
